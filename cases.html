Case Examples

Problems solved,
results delivered.

A selection of projects illustrating how we approach real-world geodata challenges.

01

BKK Data Processing App

Developed a Python application to be used by the surveying team at BKK to streamline data processing from measuring instrument to publication. Using advanced algorithms to detect patterns in the surveyed points of sub-terranian power cables. Efficiency was improved by over 99%, bringing hours spent on a task down to seconds.

Python Point Data Application Automation
02

CSIRO Navigation Data App

Improved a MATLAB program and migrated to a Python application. Translating and editing the data using an application interface from a QINSy .csv to a RUX .html format which is read by the navigational software EDCIS system on the CSIRO RV Investigator. The application saved an expensive subscription to MATLAB and improved user friendliness.

Python MATLAB Application Navigation
03

AusSeabed Processing Pipeline

Build a series of Python tools that: Automated the processing and publication of large sets of bathymetric GeoTIFF, Shapefile and Metadata records from voyages on the RV Investigator saving manual processing time by orders of magnitude and removing overnight a years-long backlog of work.

Bathymetry GDAL Python Automation
04

GNSS-IR on the Antarctic Continent

Using GNSS Interferometric Reflectometry (GNSS-IR), surface mass balance was estimated on Totten Glacier, East Antarctica, revealing spatial variability and an average snow accumulation rates. The project also validated the MARv3.10 climate model against observations, improving calibration and identifying modelling limitations.

GNSS-IR Antarctica Python Statistical Modelling
