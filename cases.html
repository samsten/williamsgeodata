A selection of projects illustrating how we approach real-world geodata challenges.

01

Coastal Erosion Monitoring Pipeline

Developed an automated Python pipeline to compare multi-year shoreline datasets derived from satellite imagery. The system detects statistically significant change, flags high-risk zones, and outputs standardised reports — replacing a previously manual quarterly process.

Remote Sensing Python Rasterio Automation
02

Municipal Infrastructure Spatial Database

Designed and migrated a fragmented collection of shapefiles and spreadsheets into a structured PostGIS database for a regional municipality. Included data cleaning scripts, schema documentation, and a QGIS project template for staff use.

PostGIS QGIS Data Modelling GeoPandas
03

LiDAR Terrain Classification for Forestry Survey

Processed raw LiDAR point cloud data over a 200 km² forested area to produce classified terrain models and canopy height maps. Delivered as GeoTIFF outputs compatible with the client's existing GIS workflows.

LiDAR PDAL Python Terrain Analysis
04

Interactive Vessel Traffic Dashboard

Built an interactive web map visualising AIS vessel tracking data for a maritime client, enabling filtering by vessel type, time window, and port zone. Deployed as a standalone HTML page with no backend dependency.
